IMAGES WEB
Les images des royaumes, des boss et des 28 chantiers sont des aperçus liés aux pages de leurs créateurs. Une connexion Internet est nécessaire pour les afficher. Les liens de crédit sont visibles sous les images et dans SOURCES_IMAGES.md.

Les images sont des références d’inspiration, pas des builds déjà présents sur Étheria. Vérifiez les conditions des auteurs avant toute réutilisation.

STRUCTURES
Le dossier assets/fiches-build-28-structures.zip contient les 28 fiches individuelles de construction.
